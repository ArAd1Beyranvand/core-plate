## Method (in this order)

1. **Find true orphans mechanically.** For every file under `lib/`, grep the repo
   for its basename as an import. Build the list of files with zero importers.
   Do not delete anything yet.
2. **Find dead symbols.** `flutter analyze` with `unused_element`,
   `unused_field`, `unused_import` and `unused_local_variable` treated as errors
   (temporarily, via `analysis_options.yaml`), plus `dart fix --dry-run`.
3. **Delete in one commit per group**, re-running the gate between groups:
   - **Group A — old theme:** `lib/screens/gallery/theme/gallery_theme.dart` and
     `lib/screens/gallery/theme/tokens.dart`. `Gap`, `Radii`, `Motion`,
     `kWideBreakpoint`, `kNarrowBreakpoint` are replaced by `NSpace`, `NRadius`,
     `NBreak`. `PlateSizes` may still be referenced by the plate cards — if it is,
     **keep it**, move it to `lib/screens/gallery/plate_sizes.dart`, and retune its
     numbers to the new card widths. Do not delete a live layout helper because it
     shares a file with dead tokens.
   - **Group B — old card chrome:** `bevel_panel.dart`, `soft_panel.dart`,
     `dashed_rule.dart`, `card_decorations.dart` — but only the ones with zero
     importers after sk8. Some may still back the poster masthead or the stamp.
   - **Group C — old shell chrome:** whatever nav widget sk4/sk5 replaced, plus any
     icon assets used only by it.
   - **Group D — unused assets:** any texture or font subset with no reference in
     `pubspec.yaml` *and* no reference in code. **Do not remove a font subset**
     (`-latin-ext`, `-arabic`) just because you cannot find a call site — the
     pubspec comment explains that Flutter falls through subsets glyph by glyph and
     that dropping one breaks metrics. Leave all four families complete.
   - **Group E — dead code inside surviving files:** unused private widgets,
     leftover blue constants, commented-out old layouts.
4. Revert the temporary `analysis_options.yaml` strictness at the end, or keep it
   if it passes cleanly — your call, but say which in the report.
