## Keyboard / keypad behaviour

- **System** mode: when the soft keyboard opens, the footer rides above it
  (`MediaQuery.viewInsets`) and the plate scrolls into view — the user must see
  the plate they are typing into.
- **Keypad** mode: wherever the current page shows the in-app keypad, it now sits
  between the scroll body and the footer, and the footer stays visible. If that
  makes the plate scroll off on a 812-tall phone, collapse the title block rather
  than hiding the plate.
- Inside the MOBILE VIEW panel (fixed 390×812 box) all of this still has to work
  — use the panel's constraints, not the window's.
