# sk12 — The country "All plates" screen

Repo: `~/StudioProjects/plate/plate_number_holder`, branch `newdesign-nocturne`.
Read `lib/screens/gallery/screens/country_detail_screen.dart`, the widgets sk11
restyled, and the Discover section of the design for the card anatomy.

## What this screen is

The page behind `All plates →` on Discover: one country, every plate it can draw,
in a grid. The design does not draw this screen explicitly — it is ours. So build
it out of the design's vocabulary rather than inventing a fourth visual language.

## Do this

- **Header**, matching Discover's header anatomy at a smaller scale:
  eyebrow `02 — DISCOVER / <COUNTRY>` in MartianMono uppercase `n500`, with
  `DISCOVER` as a back link in `accent`; the country name in Archivo w800 ≈36px;
  the package name in `NType.specId`; the country's own two-line description from
  the catalogue (the same text About shows) in Archivo 15/1.6 `n400`; then an
  `NRule`.
- **Grid**: exactly the plate card from sk11, at
  `SliverGridDelegateWithMaxCrossAxisExtent` with the design's card width; 3 columns
  at 1440, 2 at 1040, 1 under 700.
- Section padding matches Discover: `72px 64px 96px 72px`, dropping to
  `56px 40px 72px` under 1040.
- On mobile (below `NBreak.shell`) the back affordance moves into the
  `NocturneMobileHeader` trailing slot from sk5 as a left-pointing chevron, and the
  breadcrumb eyebrow drops to just `<COUNTRY>`.

## Do not

- Do not fork the plate card. Import sk11's. If it needs a size variant, add a
  parameter to the existing widget.
- Do not add filtering, sorting or search. Neither the design nor the current app
  has them, and this is a migration, not a feature.
- Do not change any plate.

## Gate

`flutter analyze` clean · `flutter test` passes · `flutter build web` succeeds.

Manual: open `All plates →` for all five countries. Every grid fills, no overflow
at 1440 / 1000 / 390, back navigation returns to Discover scrolled to that country
if the current app already does that (keep the behaviour if it exists; do not add
it if it does not).
