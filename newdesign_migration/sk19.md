## Target layout (below `NBreak.shell`)

Chrome from sk17: mobile header reading `PLATE GALLERY … 02 / DISCOVER`, bottom
bar with Discover selected.

Page body, horizontal padding 18px:

1. **Breadcrumb row** — circular back button + `DISCOVER / IRAN`, MartianMono,
   `padding: 16px 18px`, `border-bottom: 1px N.divider`. Full-bleed divider.

2. **Hero block** — **not** a bordered card on mobile: the lead-plate tinted
   gradient from sk18 runs full-bleed behind this block. Contents at mobile scale:
   name Archivo w800 ≈40px; Newsreader description 16/1.6 `n300`; the same three
   stats in one row (`4 PLATES SHOWN`, `11 specs SPECS`, `3 SECTIONS`), number
   ≈24px, labels `NType.kicker` at 10px. Allow the row to wrap only below 340px.

3. **Kicker** `IRAN_PLATE · EVERY PLATE`.

4. **Plate list** — single column of sk11 cards, full content width, `gap: 12px`.

5. **`OTHER COUNTRIES`** — new block after the list, separated by a full-bleed
   `N.divider` and ≈28px space. A kicker, then one row per *other* country (never
   the current one), each a tappable card (`N.surface`, `1px n800`, radius md,
   padding 16px):
   - left: country name Archivo 18 `n100`; package name `NType.specId` `n500`;
     a meta line in mono `n500` — `15 entries · 11 specs` (live from the
     catalogue; where the design shows a qualifier like `two live systems` or
     `nine liveries`, use the catalogue's own short note if one exists, otherwise
     omit it rather than hardcoding);
   - right: **a mini version of that country's lead plate** — ours, rendered
     read-only at ≈28px tall inside a `FittedBox`, wrapped in `IgnorePointer` and
     `ExcludeSemantics` so it never takes focus or input — then a `→` in `n400`.
   Tap → replace the current country page with that country (push-replacement in
   the nested navigator, so back still returns to Discover, not to the previous
   country).

   Show this block on mobile only unless the updated design HTML (if present in
   `design_ref/`) shows it on desktop too.
