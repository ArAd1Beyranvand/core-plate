## Target layout (desktop, page area left of the rail)

Section padding the same as Discover (`72px 64px 96px 72px`).

1. **Breadcrumb row** — a circular back button (~36px, `1px N.divider`, radius
   999, left arrow `n200`) then `DISCOVER / IRAN` in MartianMono uppercase
   +0.12em `n500`. `DISCOVER` is tappable (pops to the Discover index). Replaces
   the sk17 placeholder.

2. **Hero card** — full content width, `radius: NRadius.lg`, `1px n800` border,
   generous padding (≈48px). Background: a diagonal gradient **tinted from the
   country's lead plate** — take the dominant panel/band colour of the first
   catalogue entry's `PlateTheme` (Iran → navy), mix it ~15–20% into
   `N.surface` at the top-left, fading to `N.bg`/`#0D1017` at the bottom-right.
   Add the faint diagonal streak texture the picture shows only if it is cheap
   (a `LinearGradient` stripe, no image asset). Contents:
   - country name — Archivo w800, ≈64px, `n100`;
   - description — **Newsreader** 18/1.6, `n300`, max width ≈640px. This is the
     same country description the About page shows; source it from the same
     place, do not duplicate the string;
   - a stat row, `gap ≈ 40px`: `4 / PLATES SHOWN`, `11 specs / SPECS`,
     `3 / SECTIONS`. Number Archivo w800 ≈30px `n100`, label `NType.kicker`
     `n500`. Note the middle one prints its unit inside the number (`11 specs`).
     All three values come from the catalogue: entries in this package, distinct
     specs, and the number of source sections (Iran / Bahrain / Azerbaijan = 3).

3. **Kicker** — `IRAN_PLATE · EVERY PLATE`, MartianMono uppercase `n500`, ≈40px
   below the card.

4. **Grid** — every plate in the package, **flat, in catalogue order**, no
   per-section headers. Reuse sk11's plate card exactly (plate centred on a dark
   plinth, divider, livery name left, spec id right in `NType.specId`). 4 columns
   at 1440, 3 at ≤1280, 2 at ≤1040. Card tap → plate detail (nested navigator
   from sk17).
