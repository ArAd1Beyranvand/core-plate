## What the design specifies

Same section padding as Discover: `72px 64px 96px 72px`.

**Header** — two columns, `align-items: start`:
- left: eyebrow `03 — ABOUT` in MartianMono uppercase `n500`, then
  **`One app for every country package.`** in Archivo w800 ≈44px `n100`.
- right: two paragraphs in Archivo 16/1.65 `n300`:
  1. *"Each package ships a ~30-line example that draws one plate; the catalogue
     lives here instead, so no publishable package carries a showcase."*
  2. *"A plate is three independent render-time inputs: a PlateSpec for geometry, a
     PlateTheme for colour and a PlateCountry for the panel block. Nothing in this
     app depends on a country package knowing about any other, and no country
     package depends on this app."*
  Take the exact strings from the design file.

Then an `NRule`.

**`COUNTRIES`** kicker, then one row per country, each row a grid:
`name + package | description | spec count`, separated by solid 1px `divider`:
- `Iran` in Archivo w800 18 `n100`, then `iran_plate` in `NType.specId` `n500`;
- the description in Archivo 15/1.6 `n300`, ending in the `See <pkg>/README.md`
  sentence — render that filename in mono;
- right-aligned, `11 specs` in `NType.specId` `accent`.
Five rows: Iran, Palestine, Yemen, Lebanon, Germany. Take the copy from the design
but the **spec counts from the catalogue**, same rule as everywhere else.

**`BUILT AGAINST`** kicker, then one row per dependency, each showing the package
name in Archivo w800 15 `n100` above its version in `NType.specId` `n500`, with
two right-aligned ghost link buttons: `pub.dev` and `GitHub`, each with its small
icon. Packages: `core_plate`, `core_plate_bloc`, `plate_keypad`, `iran_plate`,
`germany_plate`, and the rest of the country packages.

Versions must come from the real resolved dependency set, not a hardcoded list —
read them from `pubspec.lock` at build time via a generated constant, or from the
existing mechanism if the current About page already does this. If it hardcodes
them today, leave a `// TODO` and keep hardcoding rather than inventing a build
step in this prompt; say so in the report.

## Responsive

header's two columns stack, the country rows become stacked blocks with the spec
count moving under the name.
