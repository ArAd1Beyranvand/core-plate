## What was lost

Before sk8 the showcase had **three callout sets — one per device (mobile,
tablet, laptop) — of three cards each**, and `lib/poster/callout_motion.dart`
drove the swap between them:

- when a device hop starts, every card of the current set **breaks into tiles**;
  each tile flies off with its own **random velocity** (and a little spin) while
  fading to **opacity 0**;
- when the next device fades in, the next device's set **assembles from tiles**
  flying in with random velocities, fading to **opacity 1**, and lands as the
  crisp live card.

sk8 collapsed this to one static set of three cards and deleted
`callout_motion.dart`. The data file's own doc comment admits it: "The old poster
carried nine of these across three per-device sets".

## Step 3 — timing, synced to the device hop

- Tile-out runs while the device content fades out; the set flips once, at the
  halfway crossover of the morph (P12C: "built once per phase, flips once per
  hop"); tile-in runs while the new device content fades in.
- The segmented control (sk6) pinning a device triggers the same swap.
- Take durations and curves from the recovered code. If the device timeline
  changed in sk9, rescale to fit it — the cards must never be mid-tile while the
  device is at rest.
- Random velocities are **seeded once per hop** (per card, per tile) and held for
  the whole animation — never re-rolled per frame.

## Step 4 — keep the P12C performance fixes (these are why it was fast)

1. **Constant tree shape.** `TileTransition` stays in the tree at rest with
   `enabled: false` / `allowSnapshotting = false` — never
   `settled ? cards : TileTransition(cards)`. A shape change remounts every card
   on the frame it settles.
2. **No per-frame rebuilds.** The card set is built once per phase and passed as
   the `AnimatedBuilder`'s `child`; the builder only moves tiles. No
   `TextPainter.layout()`, `IntrinsicHeight` or `LayoutBuilder` work per tick.
3. **Snapshot once.** Each card is rasterised once at the start of the tile
   phase and the tiles paint slices of that image.
4. **Shadows.** The Nocturne card has no drop shadow, so the P12C "snapshot clips
   the shadow" pop should not come back. If anything outside the card's box is
   painted (a glow, a shadow), give it layout room inside the snapshot box.
5. Read `ANIMATION_PERF.md` and the P12 docs in the project; the hop must not get
   slower than the numbers recorded there.
